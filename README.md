# QQ 机器人托管平台（付费版 v0.8 · Pro）

在开源版基础上，新增**会员体系、邀请码、验证码、密保找回、后台管理系统**，面向商业化运营。

> 开源版：`qq-bot-assistant2.0` ｜ 付费版：本仓库 `qq-bot-assistant2.0-pro`

## 付费版新增

| 模块 | 说明 |
|---|---|
| 验证码 | 登录/注册需图形验证码（SVG 自绘，5 分钟有效，一次性） |
| 密码强度 | 8~64 位、必须同时含字母和数字 |
| 密保找回 | 注册时设密保问题+答案，忘记密码时验证答案即可重置 |
| 邀请码 | 注册必须邀请码，管理员后台批量生成/禁用/删除 |
| 会员计划 | 免费版 1 个机器人 / 月卡 5 个 / 买断不限量（配额强制） |
| 后台管理 | 可视化总览、用户管理（禁用/发卡）、机器人管理、邀请码管理 |
| 自动管理员 | 首次启动自动创建 `admin`，随机密码写入 `data/initial-admin.txt` |

## 部署

```bash
git clone https://github.com/sakesenqiu1/qq-bot-assistant2.0-pro.git /root/qq-bot-platform
cd /root/qq-bot-platform
sudo bash deploy/setup-server.sh   # 自动装 Node 24 + 证书 + nginx + systemd
```

部署后：
1. 看日志 `data/initial-admin.txt`（或启动日志）拿到**管理员初始密码**，登录后台
2. 后台「邀请码管理」生成邀请码发给用户
3. 用户用邀请码注册 → 登录 → 创建机器人（免费版 1 个，买月卡/买断解锁更多）
4. 后台「用户管理」发放会员、禁用账号

## 盈利模式（详见 MONETIZATION.md）

- 免费版引流（1 个机器人，功能全开）
- 月卡持续收入（5 个机器人）
- 买断高客单（不限量，终身）
- AI Key 用户自带 → 平台几乎零边际成本
- 支付：先用后台「发卡」人工收款，后续接支付宝/微信

## 功能（继承开源版全部）

多用户各自管理 QQ 机器人：AI 聊天 + 角色扮演 + 群规审查（/查违规 注入群规）+ 自动禁言（三级力度 + 去重）+ 主动检查 + 特殊词语法 + /群分析 + 密钥 AES-256-GCM 加密 + HTTPS。

## 安全

- 用户 AppSecret / API Key 用 AES-256-GCM 加密落库
- 密保答案、密码均 scrypt 加盐哈希
- 验证码防爆破登录
- `data/` 目录已被 .gitignore 排除（数据库/密钥/证书不入库）
